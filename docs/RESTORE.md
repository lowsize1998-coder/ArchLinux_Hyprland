# Порядок возвращения на Linux

## 1. Базовая Arch

Сначала установить Arch Linux x86_64 обычным способом: файловые системы,
пользователь, sudo, сеть, локаль, время, ядро, драйвер NVIDIA и загрузчик.
Не переносить старый `/etc/fstab` или параметры дисков автоматически.
Этот комплект не содержит команд разметки и не обращается к `/dev/sda`.

Зафиксированное состояние: `inventory/disk-layout.txt`, `kernel.txt`,
`hardware.txt`, `monitors.json` и `packages-all.tsv`. Для сравнения отдельных
параметров есть `system-reference/`; файл оттуда нельзя считать готовым
конфигом для других UUID, дисков или версии драйвера.

## 2. Пакеты

`scripts/install-packages.sh` без аргументов показывает назначение.
После просмотра списка выполнить с `--apply`: используется полный
`pacman -Syu --needed`, а не частичное обновление Arch.

- `packages-native-explicit.txt` — явно установленные официальные пакеты.
- `packages-native.txt` — весь установленный официальный набор, включая зависимости.
- `packages-foreign-explicit.txt` — явно установленные сторонние/AUR-пакеты.
- `packages-foreign.txt` — все сторонние пакеты.
- `packages-all.tsv` — имена и точные версии на дату снимка.

Если пакет переименован или удалён из репозитория, сначала разобраться с его
заменой. Списки фиксируют старую систему, а не обещают наличие этих имён в будущем.
AUR-пакеты устанавливать отдельно после проверки PKGBUILD; их сборка не
запускается нашим скриптом автоматически.

## 3. Домашние конфиги

Закрыть приложения, настройки которых будут заменяться. Из каталога репозитория:

```sh
python3 scripts/restore.py --verify
python3 scripts/restore.py
python3 scripts/restore.py --apply
```

При конфликте сохраняется прежний файл или ссылка и запись в `restore-map.json`.
Для ручного отката закрыть соответствующее приложение и вернуть нужный объект
из указанного backup на путь `target`. Backup не размещается в Git.

Восстановлены связи `~/dotfiles → ~/symphony`, активная тема Symphony и ссылки
из `.config`. Оба оформления, Zen и Dreamcore, остаются в дереве тем.
Восстанавливается сохранённый режим Waybar из `.local/state/waybar-display/mode`.

## 4. Инструменты вне пакетного менеджера

См. `inventory/manual-apps.json`, `npm-global.json`, `python-tools.txt` и
`docs/APPLICATIONS.md`. В частности, установить Codex CLI и Zen до использования
их launchers. После установки Node-инструментов можно восстановить требуемые
глобальные пакеты в prefix `~/.local`.

Python-инструменты Symphony ставятся в отдельное окружение:

```sh
python3 -m venv ~/.local/share/symphony-tools
~/.local/share/symphony-tools/bin/python -m pip install -r inventory/python-tools.txt
ln -sfn ../share/symphony-tools/bin/tte ~/.local/bin/tte
```

Сохранённые версии Python-пакетов могут потребовать адаптации под будущий Python.
Для `live-server` установить пакет из сохранённого npm-списка с пользовательским
prefix: `npm install --global --prefix "$HOME/.local" live-server`.

## 5. Приложения и сеанс

Настроить профили Zen и Obsidian, применить Spicetify/Vencord, войти в аккаунты.
Затем запустить `bash scripts/activate-desktop.sh --apply` и войти в сеанс
Hyprland через UWSM. Службы не запускаются в неподготовленном текущем сеансе.

Мониторы сохранены: DP-2 — 2560×1440 около 240 Hz; BenQ XL2411P слева —
1920×1080 144 Hz. Если изменятся порты, названия или сами мониторы, обновить
`~/.config/hypr/local.lua`. EN/RU переключается через Alt+Space.

Системные службы SDDM, NetworkManager, Bluetooth, PipeWire и порталы проверить
после установки. Их старый список записан в `inventory/enabled-system-units.txt`.
Службы Happ/AmneziaVPN/zapret устанавливаются своими средствами после отдельной
настройки и в автоматическое включение нашим скриптом не входят.

## 6. Проверка

```sh
hyprctl configerrors
systemctl --user --failed
systemctl --user status symphony-waybar.service
awww query
```

Проверить Rofi, обе раскладки, оба монитора, обои, звук, хоткеи, Waybar, запуск
приложений, ссылки из других приложений, выбор файла, чтение PDF и экранный захват.
Памятки: `~/Инструкции/00 — Начните здесь.pdf`.

## Точность снимка

Сейчас проведены проверка файлов/ссылок, проверка целостности и тест развёртывания
в отдельный временный домашний каталог с другим путём. Пакеты на чистую Arch
в рамках экспорта не устанавливались, перезагрузка в восстановленную ОС не
выполнялась. Это проверенный перенос конфигурации, но не испытание полной
переустановки ОС. Список версий помогает отделять будущие обновления от ошибок
собственных конфигов.
