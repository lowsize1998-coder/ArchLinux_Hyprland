# Восстановление приложений

## Рабочий стол и терминалы

Hyprland Lua, Waybar, Rofi, swaync, swayOSD, GTK/Qt, Dolphin, Yazi, Ghostty,
Kitty, Alacritty, Fish, tmux, btop, rmpc, MPD, редакторы и пользовательские
службы восстанавливаются из `home/`. Иконки и все установленные темы Symphony
с обоями включены. Настройки полного набора приложений сверяются по
`inventory/applications.json` и спискам пакетов.

Старые `symphony-finish-setup`, `symphony-restore`, `install.sh`, `boot.sh` и
`uninstall.sh` сохранены как часть исходников. Они относятся к прежней установке;
не использовать их вместо нашего `scripts/restore.py`.

### Waybar

Исправленный x86_64-бинарник 0.15.0 сохранён в
`home/.local/lib/waybar-lua-0.15.0/`; службы и drop-in указывают на него.
Исходный ZIP и патчи PR #5013/#5043 — в `build/waybar/`.
Если будущие библиотеки Arch изменят ABI, проверить `ldd` и пересобрать Waybar.
Для сборки используются Meson/Ninja, зависимости из исходного `meson.build`,
а при необходимости современные исправления upstream. `*-native.patch` —
исполняемые изменения применённой сборки; обычные patch сохранены для справки.
Готовый бинарник следует снова разместить по пути, указанному в службе.
В комплекте есть `scripts/build-waybar.sh`: без аргументов показывает план,
с `--apply` собирает сохранённый исходник с патчами в пользовательском кеше.
Системные файлы скрипт не заменяет. Зависимости сборки должны быть установлены.

## Zen Browser

Установить Zen, например пакет `zen-browser-bin`, и один раз запустить для
создания профиля. Launcher сохранён с поддержкой как прежнего tarball-пути,
так и `/usr/bin/zen-browser`. Затем закрыть Zen, определить реальный профиль
через `about:profiles` и выполнить:

```sh
python3 scripts/restore.py --apply --zen-profile '/реальный/путь/профиля'
```

Параметр повторно развернёт также `home/` с backup; для нескольких приложений
удобнее передать оба параметра за один запуск. В профиль попадут CSS, хоткеи
и положительный список настроек из `profiles/zen/user.js`. Не связанные с этим
списком настройки существующего user.js сохраняются. Полный профиль, cookies,
пароли, история, закладки, pinned/essential tabs и данные рабочих пространств
не копируются. Расширения перечислены в `inventory/zen-addons.json`; установить
их заново и отдельно войти в аккаунты.

## Obsidian

Восстановить собственное хранилище из отдельного личного backup или репозитория,
затем закрыть Obsidian и выполнить:

```sh
python3 scripts/restore.py --apply --vault "$HOME/Documents/MyVault/MyVault"
```

Применяется только `.obsidian`, файлы заметок не затрагиваются. Сохранены
темы, CSS snippets, хоткеи, core/community plugin lists, код установленных
плагинов и настройки Style Settings. Календарные URL, состояние окон и личные
данные плагинов исключены; при необходимости добавить источники календаря
вручную. Dreamcore Focus — Ctrl+Alt+F.

## Spotify / Spicetify

Установить Spotify через `spotify-launcher`, один раз запустить и войти,
затем полностью закрыть клиент. Экспорт содержит Spicetify и его конфиг,
темы и Dreamcore extensions. Выполнить `spicetify backup apply`, затем открыть
Spotify и проверить оформление, Shuffle+, плавную громкость и большой плеер.
При обновлении Spotify версия Spicetify может потребовать обновления.

Параметры эквалайзера и доступные параметры качества — в
`profiles/spotify/audio-prefs.txt`. Они не устанавливаются поверх аккаунта
автоматически: после входа закрыть Spotify и перенести нужные строки в prefs
созданного пользовательского профиля, сохранив остальной файл. Автовход и
сохранённые credentials не экспортировались. Выбранные настройки переходов
также проверить в интерфейсе: часть из них может храниться на стороне аккаунта.

Spotify Mini и Happ имеют сохранённые пользовательские бинарники и исходники.
Для Happ сохранены также сгенерированные Qt-ресурсы и compatibility manifest
в `.local/share/happ-dreamcore`: без них launcher оставляет штатное оформление.
При несовместимости Qt пересобрать:

```sh
bash ~/symphony/themes/dreamcore/.config/spicetify/build-mini.sh
sh ~/symphony/themes/dreamcore/.config/happ/build-loader.sh
```

Имена скриптов находятся в соответствующих папках. Перед запуском убедиться,
что установлены компилятор, pkgconf и Qt6 development files. Happ также проверяет
SHA приложения и при несовпадении версии может перейти на штатное оформление.

Старый Spotify Qt с librespot сохранён как дополнительный клиент, включая
AppImage. Его Client Secret, OAuth tokens и аккаунтный конфиг не включены;
потребуется настройка авторизации заново.

## Discord / Vencord

Установить Discord, затем Vencord по [официальной инструкции](https://vencord.dev/download/).
Сохранены Dreamcore theme, Quick CSS и безопасные UI-настройки Vencord;
у плагинов сохраняются флаги enabled, но не произвольные приватные настройки.
Vencord заново внедряется в установленную версию Discord — старый патч бинарника
не переносится. После входа проверить, что выбрана `dreamcore.theme.css`.

## Zathura / Zaread / Koodo

Zathura и её плагины устанавливаются из пакетного списка. Zaread, его лицензия,
launchers и настройки включены; LibreOffice нужен для DOCX-конвертации.
PDF-памятки восстановятся в `~/Инструкции/`. Метки прочитанных книг, история
чтения и сами личные книги не включены. Koodo theme/patch scripts сохранены;
само приложение при необходимости устанавливается штатным сохранённым helper.

## Codex / Go / Neovim / Zed

Установить Codex CLI официальным способом; версия снимка указана в
`inventory/manual-apps.json`. Модель, UI, темы и публичный Karpathy skill
включены. Выполнить вход заново; переписки и авторизация исключены.

Go, Neovim и Zed входят в пакетные списки. Сохранены конфиги и lock-файлы всех
трёх профилей Neovim. После установки дать Lazy восстановить плагины по
`lazy-lock.json`; в `nvim-go` установить необходимые Mason-инструменты и
проверить gopls, форматирование, Go tests и Delve. Кэши, рабочие проекты,
авторизация Copilot и буферы редакторов не включены.

Конфиг Delve сохранён отдельно в `.config/dlv`. Пользовательских файлов
шрифтов в `~/.local/share/fonts` и `~/.fonts` на дату экспорта не обнаружено:
шрифты восстанавливаются установленными пакетами и сохранёнными настройками UI.

## Обои и их обработка

Используемые обои тем уже включены в `home/symphony/themes/` и доступны без
повторного улучшения качества. Для дальнейшей обработки сохранены локальный
Real-ESRGAN ncnn Vulkan с моделями и лицензией в `.local/share/dreamcore-upscale`,
а также `upscale-wallpapers.py` в теме Dreamcore. Обработка запускается только
вручную; исходные личные каталоги `~/Wallpapers` и `~/UniquePhoto` целиком
не копировались. Для повторной обработки своих исходников сохранить их отдельно.

## Telegram / Mattermost / Bitwarden / Steam / VPN

Оформление Telegram и его генераторы включены; зайти в Telegram заново и
применить сохранённую локальную тему. Экспорт tdata не производится.
Mattermost содержит только общие UI-флаги: добавить адрес своего сервера и
войти вручную. Bitwarden восстановить входом в собственный аккаунт.
Steam и игры установить заново; сохранения и userdata держать в личном backup.

Happ/AmneziaVPN connection profiles и ключи исключены. Экспортировать их при
необходимости штатной функцией самого VPN-клиента в отдельное личное хранилище,
а не в GitHub. AmneziaVPN установлена вне pacman: переустановить из официального
источника. Конфиги существующего zapret и его service сохранены только как
справочные; их системное развёртывание выполняется отдельно.
