# Исходники инструкций

Видимые папки содержат самостоятельные PDF для Zathura. Файл
`00 — Начните здесь.pdf` — общий указатель и первая памятка по поиску.

`guides.json` — содержание и порядок разделов. Поиск стоит первым в каждом
документе. Персональные назначения сверены с текущими конфигами; штатные
команды и контекстные ограничения отмечены в самих документах.

Вложенные ODT — редактируемые исходники, которые можно открыть в LibreOffice.
В PDF включены текстовый слой, встроенные шрифты Noto Sans, закладки разделов
и повторяющиеся заголовки таблиц.

Для пересборки после правки `guides.json`:

```sh
python3 /home/rozetta/Инструкции/.sources/build_pdf.py
```

Используется уже установленный LibreOffice в отдельном техническом профиле.
Никакие приложения, их конфигурация и личные документы при сборке не меняются.
Автоматического обновления справочника нет: после изменения хоткеев необходимо
обновить соответствующие записи и пересобрать PDF.

Полные экспорты в приложениях: Hyprland — зарегистрированные глобальные
сочетания, Yazi — штатная карта 26.9.1 по контекстам, Ghostty — вывод
`+list-keybinds --default`, Zen — активные записи личного JSON, Neovim —
личные назначения keymaps.lua. Другие памятки содержат подтверждённые команды
и путь к полной справке приложения, если она есть. Приложениям без
подтверждённых app-хоткеев не приписываются выдуманные сочетания.

Технические результаты проверки находятся в
`~/.local/state/shortcut-guides/`.
