Рабочая папка: `/home/rozetta/symphony`; `~/dotfiles` — ссылка на неё.

Super+Ctrl+I временно включает/отключает блокировку по бездействию.

## Установка и проверка

Установлены программы рабочего стола, инструменты музыки, записи экрана,
шрифты Nerd Font, курсор Bibata Modern Ice, GTK-тема adw-gtk3-dark и Papirus.
Fish настроен как оболочка новых окон Ghostty; оболочка входа сохраняется Bash.
Панель, уведомления, обои, блокировка, OSD и буфер обмена запускаются
через пользовательские службы `symphony-*.service`.
MPD и mpd-mpris включены; музыка: `~/Music/mpd`.
Neovim использует тему, поставляемую Zen, и установленные парсеры Treesitter.
Spotify установлен и оформлен через Spicetify в тему Zen. Для музыки требуется
обычный вход в свой аккаунт. При обновлении Spotify можно заново выполнить
`spicetify backup apply`.

Резервная копия: `/home/rozetta/dotfiles-backup-20261005-221629`.
Различия с исходником: `/home/rozetta/.local/state/symphony-setup/local-changes.patch`.
Журналы установки и проверки: `/home/rozetta/.local/state/symphony-setup`.

## Возврат исходных конфигов

Команда `~/.local/bin/symphony-restore` остановит службы Symphony и восстановит
пользовательские конфиги и файлы оболочки из резервной копии.
Установленные пакеты останутся в системе. После восстановления заново войдите в сеанс.

## Основные приложения (обновление)

Терминал по умолчанию: Ghostty. Файловый менеджер: Yazi.
Super+Enter открывает Ghostty; Super+E открывает Yazi в Ghostty.
Открытие каталогов через xdg-open также направлено в Yazi.
Сочетания отправки файлов через LocalSend удалены. Удаление пакета требует
запуска пользователем `sudo pacman -R localsend-bin`: в сессии изменения
конфигов права администратора недоступны.
Для завершения запустите из нового окна Ghostty, обычным пользователем:

```bash
~/.local/bin/symphony-finish-setup
```

Скрипт проверяет доступ к текущему сеансу и конфиги, удаляет `localsend-bin` и `zed`
через sudo, проверяет отсутствие пакета, выполняет `hyprctl reload` и проверяет
ошибки, обновляет TERMINAL в окружении пользовательских служб и D-Bus,
перезапускает Waybar и проверяет активность службы. Журнал сохраняется в
`~/.local/state/symphony-setup/finish-setup-*.log`.
Уже запущенным приложениям для нового окружения может потребоваться перезапуск
или выход из сеанса / повторный вход.

При повторной проверке конфиги Hyprland и Ghostty валидны, Zen и раскладки
us,ru / Alt+Space сохранены; MIME-тип каталогов назначен `yazi.desktop`.
Удаление LocalSend и применение настроек из среды агента не выполнены:
sudo запрещён флагом `no new privileges`, сокеты Hyprland и пользовательского
systemd недоступны. Кроме того, переменная HYPRLAND_INSTANCE_SIGNATURE агента
указывает на старый экземпляр без управляющего сокета; скрипт следует запускать
из терминала текущего сеанса. Фактическое состояние пакета и рабочего стола
после запуска скрипта нужно проверять по его журналу.

## Удаление приложений и сочетаний

Удалены привязки Super+C (Zed), Alt+C (Google Календарь), Super+G (GitHub),
Super+X (X) и Super+Z (LinkedIn)
из основного Lua-конфига, прежнего bindings.conf и HOTKEYS.md. Удалено прежнее
правило размещения окон Zed. Осталось 127 привязок рабочего стола.
Google Календарь был только запуском сайта через Chromium; отдельный
пользовательский ярлык не найден. GitHub удалён только из горячих клавиш.
X и LinkedIn также были запуском сайтов через Chromium; их привязки удалены,
отдельные пользовательские ярлыки не найдены.
Удалён также хоткей Super+обратная косая черта, открывавший Devhints,
из Lua-конфига, прежнего bindings.conf и HOTKEYS.md. Отдельный ярлык не найден.
Пакет `zed` пока установлен: sudo недоступен из среды агента. Его удаление
вместе с оставшимся LocalSend добавлено в `symphony-finish-setup`.
