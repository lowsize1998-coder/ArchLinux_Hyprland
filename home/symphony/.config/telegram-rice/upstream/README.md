# Official Telegram palette

`night.palette` is `colors.tdesktop-theme` extracted from Telegram Desktop's
official `night.tdesktop-theme` at tag `v7.2.9`:

https://github.com/telegramdesktop/tdesktop/blob/v7.2.9/Telegram/Resources/themes/night.tdesktop-theme

It supplies the supported key names and aliases. `scripts/build-theme.py`
generates the local Symphony version with explicit contrast corrections.

the upstream LICENSE is retained alongside this file.

The file is public upstream data, not an export of the user's account or theme.
