# Проверка настройки

- Установлены официальные пакеты Arch: Zathura, MuPDF, DjVu, CB, PS.
- Приложение работает через Wayland, без XWayland.
- Открыты тестовые PDF, EPUB с кириллицей, CBZ, DjVu и PostScript.
- Четыре профиля проверены по реально отображённым цветам страниц.
- Alt+2 переключает профиль через нативную привязку Zathura.
- Live-обновление темы сохраняет выбранный профиль и число страниц в ряд.
- Смена профиля не перезапускает приложение.
- MuPDF прочитал EPUB после генерации epub.css; плагин поддерживает этот
  файл для пользовательского оформления текста. Сложные книги и CSS не проверялись.
- Таймер проверен для чтения, ухода в другое окно, сброса после перерыва,
  разрыва работы после сна и отключения напоминаний.
- Сервис напоминаний запущен, включён для графической сессии.
- Конфигурации Python, Bash, Lua, desktop entry и systemd проверены.
- Hyprland не сообщает ошибок конфигурации.

Памятка оставлена открытой в Zathura. Напоминание через настоящие 20 минут
не ожидалось; проверена логика счётчика с контролируемым временем.
