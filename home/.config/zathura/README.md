# Zathura · Symphony / Hyprland

Zathura установлена из официальных пакетов Arch. Плагины:

- MuPDF: PDF, EPUB, XPS / OpenXPS.
- DjVu: DJVU / DJV.
- Comic book: CBZ, CBR, CB7, CBT.
- PostScript: PS / EPS.

Это минимальная читалка с управлением с клавиатуры. В ней нет библиотеки с
обложками как в Koodo. EPUB отображается движком MuPDF постранично. Параметр
`font` меняет шрифт интерфейса; типографика EPUB настраивается отдельно через
`epubFont`, `epubFontSize`, `epubLineHeight` и `epubParagraphSpacing`.
В PDF размер текста меняется масштабированием. MOBI, FB2 и DOCX эти плагины
напрямую не поддерживают.

## Запуск

Super+Z работает на физических клавишах в раскладках US и RU. Если Zathura
уже открыта, сочетание переводит фокус на её последнее активное окно.
Иначе появляется окно выбора документа. В меню приложений есть
«Zathura · Symphony».

```bash
zathura-rice launch ~/Documents/book.pdf
zathura-rice launch ~/Documents/book.epub
```

PDF, EPUB, XPS, DjVu, комиксы и PostScript назначены открываться через
`org.pwmt.zathura.desktop`. Копия предыдущих ассоциаций сохранена в
`~/.config/mimeapps.list.before-zathura-20261006`.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Alt+1 | Цвета текущей Symphony |
| Alt+2 | Светлая кремовая бумага |
| Alt+3 | Тёмный тёплый фон |
| Alt+0 | Исходные цвета документа |
| Ctrl+Alt+↓ | Уменьшить непрозрачность окна на 5% |
| Ctrl+Alt+↑ | Увеличить непрозрачность окна на 5% |
| Ctrl+Alt+0 | Вернуть полностью непрозрачное окно |
| Ctrl+R | Включить или выключить перекрашивание |
| Ctrl+O | Открыть документ |
| Tab | Оглавление |
| /, n, N | Поиск, следующее / предыдущее совпадение |
| j, k, h, l | Прокрутка |
| J, K | Следующая / предыдущая страница |
| s, a | По ширине / целиком |
| +, -, = | Масштаб |
| d | Одна / две страницы в ряд |
| f | Перейти по ссылке |
| F9 | Скрыть / показать строку состояния |
| F11 | Полный экран |
| F6 | Перечитать настройки |
| q | Закрыть читалку |

Alt+1/2/3/0 обрабатывает Hyprland по физическим цифровым клавишам, поэтому
они работают в US и RU. Эти привязки включены только в активном окне Zathura;
в других приложениях Alt+цифры остаются доступными самому приложению.

Закладки: `:bmark имя`, список — `:blist`, переход — `:bjump имя`.
Выделенный мышью текст копируется в обычный буфер обмена.

## Настройка

`settings.json` задаёт стартовый профиль, шрифт интерфейса, промежуток между
страницами, шаги прокрутки и масштаба, цвета бумаги и тёплого режима, интервалы
напоминаний. Фон и текст режима rice берутся из активной палитры Symphony.

`custom` — дополнительные команды Zathura, которые не генерируются.

`epub-custom.css` — дополнительные стили самой книги EPUB. На основе него
и settings.json создаётся `epub.css`, который читает плагин MuPDF. После
изменения типографики нажмите F6, затем R, чтобы заново открыть EPUB. Набор
CSS у MuPDF ограничен; шрифты и сложная вёрстка могут зависеть от конкретной
книги и возможностей движка.

```text
Symphony: текущая GTK-палитра
  → appearance: цвета интерфейса
  → profiles/rice: цвета документа

settings.json → preferences и остальные профили
custom        → ваши дополнительные команды
```

После редактирования нажмите F6 или выполните:

```bash
zathura-rice reload
```

При смене Symphony hook `66-zathura-rice.sh` обновляет уже открытые окна
через собственный D-Bus интерфейс Zathura. Выбранный в каждом окне профиль,
страница и режим одной/двух страниц сохраняются. Полное перечитывание F6
восстанавливает стартовые параметры из settings.json и custom.

```bash
zathura-rice profile warm
zathura-rice profile rice
```

Эти команды меняют профиль открытых окон. Для следующих запусков поменяйте
`profile` в settings.json. `appearance`, `preferences` и файлы в `profiles/`
создаются автоматически; редактировать их вручную не нужно.

Правило в `~/.config/hypr/local.lua` задаёт непрозрачность читалки, чтобы обои
не мешали чтению. Ctrl+Alt+↓/↑ позволяет менять её от 30% до 100% с шагом
5%; стрелку можно удерживать. Ctrl+Alt+0 возвращает 100%. Эти сочетания
включены только при фокусе на Zathura и работают в US/RU. Изменение относится
ко всему окну, включая текст, и сохраняется при потере фокуса и в полном
экране. Новые окна начинают с 100%; файлы и цвета документов не меняются.
Регулировка выполняется скриптом `opacity.py` через Hyprland.
Копия исходного файла:
`~/.config/hypr/local.lua.before-zathura-rice-20261006`.

## Комфорт чтения

Сервис `zathura-breaks.service` считает время только тогда, когда окно
Zathura с документом активно. Каждые 20 минут показывает тихое напоминание
посмотреть вдаль на 20 секунд. Если другое окно активно хотя бы 20 секунд,
отсчёт начинается заново. Длительный разрыв в работе таймера, например после
сна компьютера, также сбрасывает отсчёт. Сервис не отслеживает взгляд.

Длительности задаются в settings.json. `breakMinutes: 0` отключает
напоминания постоянно. Временно остановить сервис:

```bash
zathura-rice breaks off
zathura-rice breaks on
```

Новый запуск zathura-rice снова запускает сервис. Проверить его:

```bash
zathura-rice breaks status
```

Super+Ctrl+N переключает уже существующий в вашем rice hyprsunset.
Фильтр применяется ко всему рабочему столу. В этой настройке расписание и
температура экрана не изменялись. Тёплая тема и напоминания предназначены
для комфорта чтения и не гарантируют медицинской защиты зрения.

Перекрашивание старается сохранять цвета изображений. Для сканов, схем и
документов с важными цветами можно вернуться к оригиналу через Alt+0.

Памятка PDF: `~/.local/share/zathura-rice/Начните здесь.pdf`.
Пример EPUB: `~/.local/share/zathura-rice/Начните здесь.epub`.

Документация установленной версии:

```bash
man zathura
man zathurarc
```
