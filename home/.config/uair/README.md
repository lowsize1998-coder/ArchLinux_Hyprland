# uair — Pomodoro для вашего rice

Установлен uair 0.6.3 из проверенного AUR PKGBUILD. Rust использовался только
для сборки в /tmp; компилятор в систему не устанавливался.

Настройки: `~/.config/uair/uair.toml`.

## Waybar

Таймер находится справа от названия музыки в левой части Waybar.

- ЛКМ: начать отсчёт или поставить на паузу.
- ПКМ: завершить текущий этап и перейти к следующему.
- СКМ: сбросить таймер на рабочий этап на паузе (по умолчанию 60 минут).

Часы обозначают работу, чашка — отдых. Пауза отображается приглушённым цветом.
Цвета и шрифт берутся из текущей темы Waybar.

Таймер запускается с графической сессией и изначально находится на паузе.
Перезапуск Waybar при смене темы не перезапускает отсчёт.

## Управление из терминала

Для управления уже запущенным таймером:

```bash
uairctl toggle
uairctl fetch '{name}: {time} {state}'
```

Для вывода таймера в терминале:

```bash
uairctl listen
```

Цикл: 60 минут работы → уведомление → 10 минут отдыха → уведомление →
следующий рабочий цикл на паузе. Для начала нового цикла снова выполните
`uairctl toggle`. Таймер использует цвета и шрифт вашего терминала.

Пока процесс uair работает, им можно управлять из другого терминала:

```bash
uairctl pause        # пауза
uairctl resume       # продолжить
uairctl toggle       # переключить паузу
uairctl next         # перейти от работы к отдыху
uairctl jump work    # вернуться к началу рабочего этапа
uairctl reload       # перечитать настройки
uairctl fetch '{name}: {time} {state}'
```

Ctrl+C в терминале с `uairctl listen` закрывает только этот вывод.
Остановить сам таймер можно командой `systemctl --user stop uair.service`.

## Оформление и длительности

В `uair.toml` можно поменять `duration`, имена этапов, `format`,
`time_format`, тексты состояния и команды уведомлений.
`paused_state_text` и `resumed_state_text` задают подписи паузы и отсчёта.

Длительности используют записи `25m`, `5m`, `1h 30m`. После изменений:

```bash
uairctl reload
```

Для панели уже подготовлен отдельный формат `waybar`:

```bash
uairctl listen --override waybar
```

Для Waybar поток очищается от служебного нулевого разделителя uairctl:

```bash
uairctl listen --override waybar | stdbuf -oL tr -d '\000'
```

Это сохраняет отдельную строку JSON на каждое обновление таймера.

Документация:

```bash
uair --help
uairctl --help
```
