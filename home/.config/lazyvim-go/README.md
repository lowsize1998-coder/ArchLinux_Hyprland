# LazyVim для Go

Этот профиль запускается командой `nvim-go`. Обычный `nvim` и его конфигурация не меняются.

Хоткеи рабочего стола: `Alt+N` открывает профиль в каталоге активного терминала (или в домашнем каталоге), `Alt+Shift+N` открывает учебный проект. Используется физическая клавиша N, поэтому сочетания работают в US и RU раскладках.

Включены официальные дополнения LazyVim: Go, Neotest, DAP, поиск и дерево файлов Snacks, автодополнение Blink. В Go-набор входят настройки `gopls`, форматирование через `goimports` и `gofumpt`, подключение Go-тестов и Delve.

## Запуск

Профиль установлен и проверен 8 октября 2026 года. Проверены запуск в терминале, навигация и подсказки `gopls`, форматирование, диагностика `golangci-lint`, запуск Go-тестов через Neotest и отладка с Delve: остановка на точке останова и чтение переменных.

```bash
cd ~/nvim-go-lab
nvim-go greeting.go
```

Инструменты находятся в отдельном каталоге `~/.local/share/lazyvim-go/mason/bin`. Профиль работает независимо от инструментов прежней конфигурации. `golangci-lint` запускается при открытии и сохранении файлов в проектах с `.golangci.yml`, `.golangci.yaml`, `.golangci.toml` или `.golangci.json`; базовая диагностика `gopls` работает и без этих файлов.

Для первого занятия откройте `~/nvim-go-lab/README.md`.

## Полезные клавиши

Нажимайте клавиши последовательно в обычном режиме. `Пробел` — leader.

| Клавиши | Действие |
| --- | --- |
| `Пробел Пробел` | Найти файл |
| `Пробел /` | Найти текст в проекте |
| `Пробел e` | Дерево файлов |
| `gd` | Перейти к определению |
| `gr` | Найти использования |
| `gI` | Найти реализации |
| `K` | Документация символа |
| `Пробел c r` | Переименовать символ |
| `Пробел c a` | Действия над кодом |
| `Пробел t r` | Запустить ближайший тест |
| `Пробел t t` | Запустить тесты файла |
| `Пробел t s` | Показать результаты тестов |
| `Пробел d b` | Поставить или убрать breakpoint |
| `Пробел d c` | Начать или продолжить отладку |
| `Пробел d O` | Шаг без входа в функцию |
| `Пробел d i` | Шаг с входом в функцию |
| `Пробел g g` | Открыть LazyGit |

Сохранение через `:w` автоматически форматирует Go-код и обновляет импорты. При обновлении плагинов используйте `:Lazy update`; `lazy-lock.json` сохраняет выбранные версии, а `:Lazy restore` восстанавливает их. Инструменты можно посмотреть в `:Mason`.

## Где менять настройки

- `lua/config/lazy.lua` — наборы LazyVim;
- `lua/config/options.lua` — общие параметры;
- `lua/config/keymaps.lua` — личные сочетания;
- `lua/plugins/` — собственные плагины и изменения их настроек.

Подсказки клавиш появятся после нажатия `Пробел`. Выйти из режима вставки: `Esc`. Сохранить: `:w`. Выйти: `:q`.
