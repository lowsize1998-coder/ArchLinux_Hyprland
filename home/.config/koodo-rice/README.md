# Koodo Reader для Symphony / Hyprland

Подготовлена локальная интеграция готового Koodo Reader. Само приложение
нужно загрузить командой из обычного терминала с доступом к интернету:

```bash
~/.local/bin/koodo-rice-install
~/.local/bin/koodo-rice
```

Установщик получает последний стабильный AppImage из официального GitHub,
проверяет размер и SHA256 (когда GitHub публикует digest), распаковывает его
в `~/.local/share/koodo-rice/` и подключает локальное оформление. sudo и AUR
не нужны. После установки правило Hyprland делает окно читалки непрозрачным,
чтобы обои не мешали тексту; исходный local.lua сохраняется в резервной копии.
Можно также передать уже скачанный официальный AppImage:

```bash
~/.local/bin/koodo-rice-install ~/Downloads/Koodo-Reader.AppImage
```

PDF, EPUB, FB2, MOBI, AZW и комиксы связываются с читалкой после успешной
установки. Открытие TXT, Markdown, HTML и DOCX доступно через импорт Koodo;
редактор и браузер остаются обработчиками этих общих форматов.

## Оформление

`settings.json` — шрифт, размер, межстрочный интервал, отступ абзаца,
интервал напоминаний. `custom.css` — дополнительный CSS интерфейса.
Оба файла перечитываются при изменении; приложение перезапускать не нужно.

Режимы доступны кнопками внизу справа и клавишами:

- Ctrl+Alt+1: rice — цвета текущей Symphony.
- Ctrl+Alt+2: бумага — светлый кремовый фон.
- Ctrl+Alt+3: тёплый — тёмный тёплый фон.

Размер текста по умолчанию — 24 px, интервал — 1.65, шрифт — FreeSerif
(уже установлен в системе). Цвета генерируются из активной GTK-палитры
Symphony при запуске и смене темы. Готовый `palette.json` редактировать не
нужно. Дополнительный CSS можно писать с переменными `--rice-bg`,
`--rice-fg`, `--rice-panel`, `--rice-accent`, `--rice-border`.

Оформление страниц применяется к доступным HTML-документам в iframe,
в том числе вложенным в shadow DOM. Canvas PDF, сканы, комиксы и фиксированная
вёрстка сохраняют исходное содержимое. Для PDF используйте собственные
настройки масштаба и цветов Koodo. Поддержка конкретного файла зависит от
движка Koodo; DRM-защищённые книги и абсолютно все форматы не гарантируются.

## Комфорт чтения

Каждые 20 минут чтения в активном окне появляется тихое напоминание:
посмотреть вдаль примерно на 6 метров на 20 секунд. В библиотеке и других
приложениях таймер не накапливается; длительный простой сбрасывает счётчик.
Чтобы отключить напоминания, задайте `breakMinutes: 0`.

Тёплый экран уже доступен в вашем rice: Super+Ctrl+N переключает существующий
скрипт `~/.config/hypr/scripts/nightlight` с hyprsunset. Он управляет всеми
экранами, поэтому читалка сама не меняет цветовую температуру рабочего стола.
Тема и фильтр предназначены для удобства; медицинскую защиту зрения они
не обеспечивают. Рекомендации о перерывах:
https://www.aao.org/eye-health/tips-prevention/digital-devices-your-eyes

## Обновление и возврат к оригиналу

Повторный `koodo-rice-install` ставит свежую версию отдельно и переключает
ссылку `current` после успешной распаковки и подключения оформления.
Предыдущие установки сохраняются. Библиотека использует стандартный профиль
Koodo; её данные установщик не редактирует. Встроенное обновление Koodo
может заменить локальное оформление, поэтому обновляйте этим установщиком.

Оригинальный `resources/app.asar.upstream` сохраняется рядом с изменённым
архивом. Чтобы отключить интеграцию, закройте Koodo и восстановите оригинал:

```bash
cp ~/.local/share/koodo-rice/current/resources/app.asar.upstream \
   ~/.local/share/koodo-rice/current/resources/app.asar
```

Локальная интеграция написана для личного использования на основе официального
Koodo Reader: https://github.com/koodo-reader/koodo-reader (AGPL-3.0).
CSS-селекторы и структура страниц могут меняться между выпусками. Пока
приложение не загружено, визуальная проверка и чтение реальных книг не выполнены.
