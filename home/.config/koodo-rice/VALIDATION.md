# Проверка локальной интеграции

Пройдено:
- Python, JavaScript, Bash: проверка синтаксиса.
- Desktop entry: desktop-file-validate.
- Генерация цветов: палитры Symphony, текущая тема zen.
- Изменение ASAR: сохранение данных и unpacked-записей, обновление SHA256 и
  блоков integrity, сохранение strict mode, повторное применение без дублирования.
- Независимое чтение изменённого тестового ASAR установленным Electron 43.7.7.
- Установка из тестового AppImage и сохранение предыдущей установки при сбое.
- Таймер: библиотека, активное/неактивное окно, простой, отключение напоминаний.
- Текст JavaScript для определения режима чтения компилируется.

Не выполнено:
- Скачивание официального Koodo: DNS недоступен в изоляции.
- Запуск Koodo и проверка реальных книг.
- Проверка CSS в браузере: Chromium не запустился из-за запрета setsockopt.

Локальный установщик подготовлен, но реальная установка не завершена.
