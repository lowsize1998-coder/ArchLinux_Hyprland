# Waybar 0.15.0 с исправлением Hyprland Lua

Служба symphony-waybar.service запускает этот пользовательский бинарный файл.
Официальные исправления: Alexays/Waybar PR #5013 и #5043 (исполняемые изменения).
Базовая версия 0.15.0. Системный /usr/bin/waybar сохранён.
Сведения о сборке: BUILD.json. Исходники, патчи и инструменты сборки:
/home/rozetta/.local/state/hypr-monitors/waybar-lua-build.

Исправлена отправка команд переключения рабочих столов в Hyprland с Lua.
Тест: реальные клики по цифрам на обоих мониторах успешно переключили столы.
Процессов-посредников и постоянного дополнительного опроса для этого не добавлено.

Сборка активируется через пользовательский drop-in lua-ipc.conf для службы
symphony-waybar.service. Для возвращения системного бинарника убрать только
этот drop-in, выполнить systemctl --user daemon-reload и перезапустить службу.
Оригинальные unit и другие drop-in сохраняются.
